## How to use this folder

Treat the scenario as the primary source for intended business purpose and the initial governance problem. Do not infer implementation details that the scenario does not establish. Where later artifacts add fictional vendors, architecture details, or operating assumptions, those additions should be traceable to the assumptions register.

The scenario's core operating principle is controlled innovation: governance intensity should increase with potential impact rather than applying identical review to every AI use case.
