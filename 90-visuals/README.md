## Evidence caution

A visual is an explanatory aid. It should not be treated as authoritative evidence of system configuration, control implementation, legal compliance, or operating effectiveness unless the underlying facts are independently supported by controlled records.

Where a visual conflicts with a controlled register, assessment, policy, or approved decision, the controlled source should take precedence and the visual should be updated.
