# Duckworks AIMS Internal Audit Programme

Version: 1.0  
Release: Project W.I.N.G. v1.7  
As of: 2026-09-09

This folder establishes the risk-based internal-audit planning and control-assurance layer for the Duckworks AI management system (AIMS). It converts the approved 45-control applicability register into an audit universe, a 2026–2027 programme and a first-wave evidence-substantiation review.

## Current result

- Audit universe: 45 controls (2 P1 Immediate, 23 P2 High and 20 P3 Medium).
- First-wave engagement: `AUD-AIMS-2026-001`, covering `DD-01` and `FF-01`.
- First-wave conclusion: both source `Implemented` labels are **not demonstrated** by the reviewed repository evidence.
- Findings: `IAF-2026-002` and `IAF-2026-003`, both High and open pending management response.
- Automated finding closures: zero.
- Production-effectiveness, ISO/IEC 42001 conformity and certification claims: zero.

## Defensible boundary

The first-wave work is a bounded synthetic repository evidence review. The named auditor role, competence, organizational independence and approval have not been verified. Therefore the package is not evidence of a completed independent enterprise audit, production operation, control effectiveness, legal compliance, ISO/IEC 42001 conformity or certification.

Only an authorized and independent human reviewer may approve the programme, issue formal audit conclusions, accept risk, approve a status change or close a finding.
